introduction to programming

1.programming is the process of writing instructions for a computer to perform a specific task.

1.compiler: 
   a program that converts high-level language code into machine language code.
   at once it translates the entire code into machine language code.
EX: c,c++,java

2.interpreter:
   a program that executes high-level language code directly, without converting it into machine language code.
   it translates and executes the code line by line.
EX: python,javascript

3.high-level language:
   a programming language that is easy for humans to read and write, but is converted into machine language code by a compiler or interpreter.
   easy to learn and use.
   but its slower and less efficient than low-level languages.
   but they need translation to be understood by the computer.
EX: python,java,c++

4.machine language:
   a programming language that is written in binary code, which is the language that computers understand.

5.programming language:
   a language used to write instructions for a computer to perform a specific task.


6.debugging:
   the process of finding and fixing errors in a program.
7.low-level language:
   a programming language that is closer to machine language code, but is still readable by humans.
   interact more directly with the computer's hardware.
   faster and more efficient than high-level languages.
   harder to learn and use.
EX: assembly language

********
type() function is used to know the data type of a variable or value.
example:
a=10.5
print(type(a))  #output: <class 'float'>
***********
boolean data type:
1.bool - True or False
example:
is_raining = True
print(is_raining)  #output: True
print(type(is_raining))  #output: <class 'bool'>
*************
none data type:
1.none - represents the absence of a value
example:
a = None
print(a)  #output: None
print(type(a))  #output: <class 'NoneType'>
